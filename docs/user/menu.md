# Menu

The menu lists every screen. Each row shows a number, the screen name, and what the screen holds.

To open the menu, press F4 (MENU) on the KEYER screen. Most other screens return to the menu with F4 (BACK).

| Row | Opens | Page |
| - | - | - |
| 01 KEYER | The main screen: speed, tone, volume, timing tape and decode. | [Keyer](keyer.md) |
| 02 TIMING | A zoomed timing tape and histograms of your keying. | [Timing](timing.md) |
| 03 RECEIVE | The Koch drill. F2 on that screen moves to the other drills and the ragchew. | [Receive drills](receive.md) |
| 04 POTA | Activate a park and work a pileup. | [Activate a park or summit](activate.md) |
| 05 SOTA | Activate a summit and work a pileup. | [Activate a park or summit](activate.md) |
| 06 HUNT | Hunt activators on parks and summits. | [Hunt](hunt.md) |
| 07 LETTERS | Your accuracy for each character, and your mixups. | [Letters](letters.md) |
| 08 PROGRESS | Practice time and totals for recent sessions. | [Progress](progress.md) |
| 09 SETTINGS | Every setting. | [Settings](settings.md) |
| 10 SYSTEM | Version, hardware checks and battery. | [System](system.md) |
| 11 RADIO | The decoder board of the Pro model. This row shows only when DECODER BOARD is ON. | [Radio](radio.md) |

The header shows your callsign.

## Controls

| Control | Action |
| - | - |
| F1 (SET) | Opens the settings at the KEYER tab. |
| F2, F3 | Nothing. |
| F4 (BACK) | Opens the KEYER screen. |
| Dial turn | Moves the selection up or down. |
| Dial click | Opens the selected screen. |
| Dial hold | Turns the device off. |
| Key | Nothing more. |
