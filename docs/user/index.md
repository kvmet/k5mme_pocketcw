## Terms

This manual uses these ham radio terms.

| Term | Meaning |
| - | - |
| WPM | Words per minute. The standard word is PARIS, so one dot lasts 1200 / WPM milliseconds. |
| Dot, dash | The short and the long element. A dash is 3 dots long. In this manual one dot length is also called one unit. |
| Gap | The silence between elements (1 unit), between characters (3 units) and between words (7 units). |
| Koch method | A way to learn: start with two characters at full speed, and add one character each time you copy 90 % of them right. |
| Farnsworth timing | Characters are sent at full speed, with longer gaps between characters and words, so the text arrives at a lower speed. |
| QSO | A radio contact between two stations. |
| Over | One station's turn to send in a QSO. |
| Copy | To receive Morse code and understand or write it down. |
| CQ | A general call: any station may answer. |
| RST | A signal report, such as 599. 5NN is 599 with the 9s sent as N. |
| Prosign | Two letters sent as one character, with no gap. This manual writes them in angle brackets, such as `<AR>`, `<BK>`, `<KN>` and `<SK>`. |
| POTA, SOTA | Parks on the Air and Summits on the Air: programs where an activator operates from a park or a summit and hunters contact the activator. |
| P2P | Park to park: a QSO between two activators. |
| Pileup | Several stations that call at the same time. |
| Ragchew | A long, chatty QSO. |
| Fist | How a person keys: their small timing errors. |
| QRS, AGN, QRZ | Please send slower; send again; who is calling me. |
| TU, 73, 72 | Thank you; best regards; best regards at low power (common in POTA). |
| Sidetone | The tone you hear while you key. |
