# Progress

The PROGRESS screen shows your practice over recent sessions. A session is one time the device is on, from turn on to turn off. The device has no clock, so sessions take the place of days.

Open STATS in the [menu](menu.md), then PROGRESS. The header shows how many sessions the device keeps, such as `12 SESSIONS`.

The device keeps the last 32 sessions. A session starts to count at the first thing you do, so a turn on with no practice does not take a place. When all 32 places are full, a new session replaces the oldest.

## What counts

| Column | What it counts |
| - | - |
| TIME | Time while you key, on any screen. Time between two key presses counts when the gap is 60 seconds or less. |
| SENT | Characters you sent on the key, on any screen. |
| COPY | Percent right in [receive drills](receive.md) and [ragchew](ragchew.md) quizzes. |
| QSOS | QSOs you logged when you [activate](activate.md) or [hunt](hunt.md). |

## What the screen shows

The chart shows the last 14 sessions, the newest at the right. `NOW` marks the session in progress.

- A filled bar shows the minutes of practice in that session.
- A hollow square shows the COPY percent in that session. A session with no receive practice has no square.

The scale at the left shows the most minutes in the chart, 10 minutes or more.

The table under the chart has two rows:

- NOW: this session. `-` means nothing counted yet.
- LAST n: all the sessions the device keeps, added together.

Time shows as minutes, such as `25M`, or as hours and minutes, such as `1H05`. `-` in COPY means no receive practice.

Before your first session, the chart says `NOTHING YET: START KEYING`.

## Controls

| Control | Action |
| - | - |
| F1, F3 | Nothing. |
| F2 (LTRS) | Opens [Letters](letters.md). |
| F4 (BACK) | Opens the STATS list of the [menu](menu.md). |
| Dial turn | Changes the focused header value. See [Header values](controls.md#header-values). |
| Dial click | Moves the focus to the next header value. |
| Dial hold | Turns the device off. |
| Key | Nothing more. |
